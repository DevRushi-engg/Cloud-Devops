# `cd` — Change Directory

## What it does
Moves you into a different directory.

## Syntax
```bash
cd [destination]
```

## Common Variants

| Command | What it does |
|---------|--------------|
| `cd <folder>` | Move into a subfolder |
| `cd ..` | Move up one level |
| `cd ~` | Jump straight to home directory |
| `cd -` | Jump back to the previous directory |
| `cd /` | Go to the root of the filesystem |

## Examples
```bash
# move into a subfolder
$ cd practice

# go up one level
$ cd ..

# go home
$ cd ~

# toggle between two directories
$ cd -
```

## Absolute vs Relative Paths

```bash
# absolute path — always starts with /
# works from anywhere
$ cd /home/user/practice/logs

# relative path — starts from where you are now
# only works if 'logs' exists in current directory
$ cd logs
```

### Special path symbols
| Symbol | Means |
|--------|-------|
| `.` | Current directory ("here") |
| `..` | One level up |
| `~` | Your home directory (`/home/<username>`) |
| `/` | Root of the entire filesystem |

## My Terminal Output
```bash
rushi@rushi:~$ cd Cloud-Devops
rushi@rushi:~/Cloud-Devops$ 

rushi@rushi:~/Cloud-Devops$ cd ..
rushi@rushi:~$ 

rushi@rushi:~/Cloud-Devops/Linux$ cd ~
rushi@rushi:~$ 

rushi@rushi:~$ cd -
/home/rushi/Cloud-Devops/Linux
rushi@rushi:~/Cloud-Devops/Linux$ 

rushi@rushi:~/Cloud-Devops/Linux$ cd /
rushi@rushi:/$ 
```
## Key Points
- `~` is shorthand for `/home/<your-username>`
- `$` in the prompt means normal user; `#` means root
- Use `pwd` after `cd` if you're unsure where you landed
