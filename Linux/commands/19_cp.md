# cp — Copy Files and Folders

## What it does
Creates a duplicate of a file or folder at a new location.
The original always stays behind.

## Syntax
```bash
cp source target           # copy a file
cp -r logs/ logs_backup/   # copy a whole folder
cp -a src/ dest/           # archive mode, preserves timestamps & permissions
```

## My Terminal Output
```bash
rushi@rushi:~/project$ cp notes.txt backup.txt
rushi@rushi:~/project$ ls
backup.txt  notes.txt

rushi@rushi:~/project$ cp -r logs/ logs_backup/
rushi@rushi:~/project$ ls
logs  logs_backup
```

## Flags
| Flag | What it does |
|------|-------------|
| `-r` | Recursive — required to copy folders |
| `-a` | Archive mode — preserves permissions, timestamps, symlinks |
| `-i` | Prompts before overwriting an existing file |

## Key Points
- Without `-r` you cannot copy a folder — it will error
- `-a` is better than `-r` when you want an exact clone
- The original file is never touched

## When I use this
Taking a backup before editing a config file or script.
