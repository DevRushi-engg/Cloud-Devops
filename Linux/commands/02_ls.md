# `ls` — List Directory Contents

## What it does
Lists files and folders in the current (or specified) directory.

## Syntax
```bash
ls [flags] [path]
```

## Common Flags

| Flag | What it does |
|------|--------------|
| (none) | Plain file/folder names |
| `-l` | Long format — permissions, owner, size, date |
| `-a` | Include hidden dotfiles (files starting with `.`) |
| `-h` | Human-readable sizes (KB, MB instead of bytes) |
| `-la` | Long format + hidden files (most common combo) |
| `-lh` | Long format + human-readable sizes |

## Examples
```bash
# basic list
$ ls

# long format
$ ls -l

# include hidden files
$ ls -la

# human readable sizes
$ ls -lh

# list a specific path
$ ls -la /var/log
```

## Reading `ls -l` output
```
drwxr-xr-x  2 user user 4096 Jul 4 10:02 logs
│              │    │    │    │            └── name
│              │    │    │    └── date modified
│              │    │    └── size in bytes
│              │    └── group
│              └── owner
└── type + permissions (d=directory, -=file, l=symlink)
```

## Key Points
- `-l` and `-a` can combine: `-la` or `-al` — same result
- Hidden files start with a dot (`.bashrc`, `.env`) — only visible with `-a`
