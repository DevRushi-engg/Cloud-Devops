# wc — Count Lines, Words, Bytes

## What it does
Counts lines, words, or bytes in a file.

## Syntax
```bash
wc -l app.log        # number of lines
wc -w notes.txt      # number of words
wc -c app.log        # number of bytes
```

## My Terminal Output
```bash
rushi@rushi:~/practice$ wc -l logs/app.log
3 logs/app.log

rushi@rushi:~/practice$ cat logs/app.log | wc -l
3
```

## Flags
| Flag | What it does |
|------|-------------|
| `-l` | Count lines |
| `-w` | Count words |
| `-c` | Count bytes |

## When I use this
Counting how many log lines match an error, or checking file sizes quickly.
