# ps — List Running Processes

## What it does
Shows a snapshot of currently running processes.

## Syntax
```bash
ps              # your processes only
ps aux          # every process on the system with full detail
ps aux | grep nginx     # find a specific process by name
```

## My Terminal Output
```bash
rushi@rushi:~$ ps aux | grep nginx
root      1234  0.0  0.1  55380  1234 ?  Ss  10:00  0:00 nginx: master process
www-data  1235  0.0  0.0  55380   890 ?  S   10:00  0:00 nginx: worker process

rushi@rushi:~$ ps aux | head -5
USER       PID %CPU %MEM    VSZ   RSS TTY  STAT START   TIME COMMAND
root         1  0.0  0.1 168940 11234 ?    Ss   09:00   0:01 /sbin/init
```

## Column Reference
| Column | Meaning |
|--------|---------|
| `PID` | Process ID — the number you act on |
| `%CPU` | CPU usage percentage |
| `%MEM` | Memory usage percentage |
| `STAT` | State: S=sleeping, R=running, Z=zombie |
| `COMMAND` | What is actually running |

## Flags
| Flag | What it does |
|------|-------------|
| `a` | Show processes from all users |
| `u` | Show user-oriented format with details |
| `x` | Include processes not attached to a terminal |

## Key Points
- `ps aux` is the standard — use it every time
- PID column is what you pass to `kill`
- Pipe to `grep` to find a specific service
- `Z` in STAT means zombie — a dead process not yet cleaned up

## When I use this
Finding the PID of a stuck process before killing it, confirming
a service started its worker processes correctly.
