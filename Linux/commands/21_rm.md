# rm — Delete Files and Folders

## What it does
Permanently deletes files or folders.
There is no recycle bin. Deleted means gone.

## Syntax
```bash
rm file.txt               # delete a single file
rm -r old_logs/           # delete a folder and everything inside
rm -i important.txt       # ask before each delete
rm *.tmp                  # delete all .tmp files
```

## My Terminal Output
```bash
rushi@rushi:~/project$ rm file.txt
rushi@rushi:~/project$ ls
logs  notes.txt

rushi@rushi:~/project$ rm -i notes.txt
rm: remove regular file 'notes.txt'? y
```

## Flags
| Flag | What it does |
|------|-------------|
| `-r` | Recursive — removes a folder and all its contents |
| `-i` | Interactive — prompts before every deletion |
| `-f` | Force — no prompts, ignores missing files |

## ⚠️ WARNING — Never run this
```bash
rm -rf /    # tries to erase the entire system
rm -rf /*   # same result
```
- `-rf` means recursive + force: no questions, no mercy
- Always check `pwd` and re-read the path before running `rm -r`
- Habit: write the path first, re-read it, then add `rm` at the front

## Safe habit
```bash
# test with ls before deleting
ls *.log        # confirm what matches
rm *.log        # then delete
```

## When I use this
Cleaning up temp files, old logs, and build artifacts — always with `-i` on important directories.
