# clear — Clean Up the Terminal

## What it does
Wipes the visible terminal screen so you can start fresh.

## Syntax
```bash
clear
# or keyboard shortcut
Ctrl + L
```

## Key Points
- Only clears the visible screen — your history is NOT deleted
- You can still scroll up to see previous output
- `Ctrl+L` does the exact same thing without typing

## When I use this
When the terminal gets cluttered and I want a clean view.
