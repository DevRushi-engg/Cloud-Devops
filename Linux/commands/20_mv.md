# mv — Move or Rename

## What it does
Moves a file to a new location OR renames it.
There is no separate rename command in Linux — mv does both jobs.

## Syntax
```bash
mv old.txt new.txt         # rename a file
mv report.txt logs/        # move into a folder
mv logs/ archive/logs/     # move a whole folder
```

## My Terminal Output
```bash
rushi@rushi:~/project$ mv old.txt new.txt
rushi@rushi:~/project$ ls
new.txt

rushi@rushi:~/project$ mv new.txt logs/
rushi@rushi:~/project$ ls logs/
new.txt
```

## Key Points
- Rename = move to the same folder with a new name
- Unlike `cp`, the original does NOT stay behind
- No `-r` needed — mv handles folders as they are
- Moving within the same filesystem is instant (just renames the path)

## When I use this
Renaming files to follow a naming convention, or moving build output to an archive folder.
