# ip — Show Network Interfaces and Routing

## What it does
Shows your machine's IP addresses, network interfaces, and
how network traffic is routed. The modern replacement for `ifconfig`.

## Syntax
```bash
ip a              # all interfaces and their IP addresses
ip addr           # same as ip a
ip r              # routing table — how traffic leaves the machine
ip link           # interface status (up/down)
```

## My Terminal Output
```bash
rushi@rushi:~$ ip a
1: lo: <LOOPBACK,UP> mtu 65536
    inet 127.0.0.1/8 scope host lo

2: eth0: <BROADCAST,MULTICAST,UP> mtu 1500
    inet 192.168.1.100/24 brd 192.168.1.255 scope global eth0

rushi@rushi:~$ ip r
default via 192.168.1.1 dev eth0
192.168.1.0/24 dev eth0 proto kernel scope link
```

## Key Points
- Look for your IP under `eth0` (wired) or `wlan0` (wireless)
- `127.0.0.1` is localhost — your machine talking to itself
- `ip r` shows the default gateway — where traffic goes when leaving your network
- `ip a` replaces the old `ifconfig` command
- In cloud VMs you will see `ens3` or `ens5` instead of `eth0`

## When I use this
Confirming my machine's IP before SSH-ing in from another machine,
checking network interface status when connectivity fails.
