# pwd — Print Working Directory

## What it does
Shows the full absolute path of your current location in the filesystem.
You are always "somewhere" in Linux. pwd tells you exactly where.

## Syntax
```bash
pwd
```

## My Terminal Output
```bash
rushi@rushi:~/Cloud-Devops$ pwd
/home/rushi/Cloud-Devops
```

## Key Points
- No flags needed for everyday use
- First command to run when you feel lost in the terminal
- ~ in the prompt is shorthand for /home/username

## When I'd use this
Before running any command that involves a file path, to confirm I'm in the right directory.
