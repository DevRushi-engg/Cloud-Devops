# Git & GitHub

This folder contains my learning notes of the Git & GitHub.

## What is Git?
Git is a version control system that tracks changes to files over time.
It lets you save snapshots of your work, go back to any earlier version,
and collaborate with others without overwriting each other's changes.

## What is GitHub?
GitHub is a website that hosts Git repositories in the cloud.
It adds collaboration on top of Git — sharing code, reviewing changes,
and backing up your work remotely.
